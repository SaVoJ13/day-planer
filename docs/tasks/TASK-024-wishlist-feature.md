## 1. Опис вимоги Власника
- **Запит:**
  > «тепер треба створити опцію WishLIst
  > де людина буде створювати список побажань на День Народження або інші свята і надавши запрошення інші користувачі можуть обирати подарунок
  > до списку можна додавати посилання на товар з магазин»

- **Ключові функціональні вимоги:**
  1. **Створення списку бажань (Wishlist):**
     - Можливість створити Wishlist окремо від звичайних покупок (із зазначенням свята: День народження, Новий рік, Весілля, Новосілля, Інше свято).
     - Розділення на головному екрані: вкладки/фільтр «🛒 Покупки» та «🎁 Бажання (Wishlist)».
  2. **Елементи списку бажань:**
     - Назва подарунка / бажання.
     - **Посилання на товар з магазину (URL):** валідація, збереження та кнопка відкриття посилання у браузері (`Intent.ACTION_VIEW`).
     - Швидке додавання URL з буфера обміну.
  3. **Спільний доступ та вибір/бронювання подарунка друзями:**
     - Генерація коду запрошення (6 знаків) для надсилання друзям через месенджери.
     - Друзі, що відкривають спільний Wishlist за кодом, бачать список подарунків з посиланнями на магазини.
     - Друг може **обрати / забронювати подарунок** («🎁 Обрати як подарунок / Забронювати»).
     - Після бронювання подарунок отримує статус «Заброньовано: [Ім'я]», щоб інші друзі не придбали той самий подарунок.
     - Можливість скасувати бронювання.
  4. **Локалізація на 4 мови:**
     - Всі тексти, підказки, кнопки та назви свят перекладені для `uk`, `en`, `pl`, `ru`.

---

## 2. Архітектурні зміни
1. **База даних Room:**
   - `ShoppingListEntity`: додано `isWishlist: Boolean = false`, `occasion: String? = null`.
   - `ShoppingItemEntity`: додано `url: String? = null`, `isReserved: Boolean = false`, `reservedBy: String? = null`.
   - `AppDatabase`: версія 4, міграція `MIGRATION_3_4`.
   - `ShoppingItemDao`: додано метод `updateReservationStatus(itemId, isReserved, reservedBy)`.
2. **Моделі домену та репозиторій:**
   - `ShoppingList`: додано `isWishlist: Boolean`, `occasion: String?`.
   - `ShoppingItem`: додано `url: String?`, `isReserved: Boolean`, `reservedBy: String?`.
   - `ShoppingRepository`: методи оновлення бронювання, створення вішлиста з подією, додавання товарів з посиланням.
   - `GroupShoppingRepository` / DTO: синхронізація полів `isWishlist`, `occasion`, `url`, `isReserved`, `reservedBy`.
3. **UI / Jetpack Compose:**
   - `ListsScreen`: перемикач вкладок («🛒 Покупки» / «🎁 Бажання»), створення Wishlist з вибором події, бейджі та картки вішлистів.
   - `ListDetailsScreen`: адаптація під Wishlist (кнопка переходу за URL до магазину, діалог додавання посилання, кнопка вибору/бронювання подарунка друзями зі збереженням імені).
4. **Локалізація:** ресурси рядків у 5 файлах (`values`, `values-uk`, `values-en`, `values-pl`, `values-ru`).
