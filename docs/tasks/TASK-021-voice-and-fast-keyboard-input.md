## 1. Опис проблеми та потреби користувача
- **Звернення Власника:** «не зручно додавати продукти до листу покупок, треба додати голосовий набір, і якось оптимізувати набор з клавіатури, бо додавання по одному продукту це не зручно».
- **Аналіз поточних обмежень:**
  1. Додавання вимагає введення одного товару та натискання кнопки «+» на екрані. Кнопка Enter на клавіатурі не додає товар автоматично.
  2. Якщо користувач вводить список через кому (`хліб, молоко, масло`), створюється один єдиний товар з усім текстом, замість трьох окремих позицій.
  3. Відсутній голосовий ввід, який дозволяє надиктувати список покупок за 5 секунд.
  4. Часті товари сховані за окремою шторкою («зірочкою»), замість того, щоб бути одразу під рукою над полем введення.

## 2. Комплексне рішення

### 2.1. Голосовий набір (Native Speech Recognition):
- Додати іконку мікрофона `Icons.Default.Mic` у поле швидкого додавання.
- Використати системний `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` через Compose ActivityResultLauncher.
- Безпека та приватність: системне вікно Google/Samsung розпізнавання не потребує небезпечного дозволу `RECORD_AUDIO` від нашого додатку, що зберігає чисту декларацію Google Play Data Safety.
- Підтримка мови відповідно до поточної локалі (uk-UA, en-US, pl-PL, ru-RU).
- Розумний парсинг розпізнаного мовлення: розділення за комами, сполучниками («і», «та», «and») або паузами. Якщо розпізнано кілька товарів — відкриття зручного діалогу підтвердження з чекбоксами для перевірки перед додаванням. Якщо один товар — миттєве додавання.

### 2.2. Оптимізація введення з клавіатури:
- **Підтримка клавіші Enter/Done на клавіатурі:** `KeyboardOptions(imeAction = ImeAction.Done)` та `KeyboardActions(onDone = { ... })` — натискання Enter на цифровій/текстовій клавіатурі додає товар і одразу залишає фокус для наступного товару без необхідності тягнутися до кнопки «+».
- **Автоматичне розділення кількох товарів:** Якщо в полі введено рядок із комами, крапками з комою або перенесеннями рядків (`молоко, хліб, сир, яблука`), система автоматично розбиває його на окремі товари та додає всі відразу.

### 2.3. Стрічка швидких підказок (Quick Suggestion Chips):
- Прямо над полем вводу відображати горизонтальну смугу швидких підказок із найчастіших покупок (або популярних товарів за замовчуванням).
- Одне натискання на чіп (наприклад, `+ Молоко`) миттєво додає товар у список без відкриття клавіатури.
