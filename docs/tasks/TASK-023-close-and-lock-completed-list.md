## 1. Опис вимоги Власника
- **Запит:** «коли список буде повністью зазначений як куплений має зявитись функція закрити список, після закриття він замикається».
- **Логіка поведінки:**
  1. Коли всі товари в списку позначені як куплені (`items.isNotEmpty() && activeItems.isEmpty()`), з'являється помітна функція **«Закрити список»** (кнопка із замком у вітальному банері та у верхньому меню дій).
  2. Після натискання список переходить у статус **замкнено** (`isLocked = true`):
     - В базі даних додається поле `is_locked` (міграція Room `MIGRATION_2_3`).
     - В деталях списку вимикається випадкове редагування / зняття позначок товарів, ховається поле вводу нового товару, відображається статус «🔒 Список закрито».
     - Присутня зворотна дія «Відімкнути список» (на випадок потреби внести зміни).
     - На головному екрані «Мої списки» картка отримує бейдж «🔒 Закрито», а меню картки дозволяє швидко закрити або відімкнути список.

## 2. Архітектурні зміни
1. **База даних Room:**
   - `ShoppingListEntity`: додано `@ColumnInfo(name = "is_locked") val isLocked: Boolean = false`.
   - `AppDatabase`: підвищення версії до 3, створення `MIGRATION_2_3` (`ALTER TABLE shopping_lists ADD COLUMN is_locked INTEGER NOT NULL DEFAULT 0`).
   - `ShoppingListDao`: метод `updateLockedStatus(listId: Long, isLocked: Boolean)`.
2. **Модель даних та репозиторій:**
   - `ShoppingList`: додано `val isLocked: Boolean = false`.
   - `ShoppingRepository`: `suspend fun setListLocked(listId: Long, isLocked: Boolean)`.
3. **UI / Compose:**
   - `ListDetailsScreen`: вітальний банер закриття списку при 100% готовності, блокування елементів при `isLocked == true`, кнопка відімкнення.
   - `ListsScreen`: відображення бейджа `🔒 Закрито` та пункт меню закриття/відімкнення.
4. **Локалізація:** 9 нових рядків у 5 файлах (`values`, `values-uk`, `values-en`, `values-pl`, `values-ru`).
