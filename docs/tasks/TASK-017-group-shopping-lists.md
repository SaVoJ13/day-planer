## 1. Мета та опис
Додати можливість спільного ведення списків покупок для груп людей (сім'ї, друзі на пікнік/вечірку, колеги):
1. **Створення спільного доступу:** Власник списку натискає «Поділитися» -> список отримує статус спільного, генерується унікальний 6-значний код (наприклад `K7P9X2`) та формується посилання для відправки в месенджери (Telegram, Viber тощо).
2. **Приєднання до списку:** Будь-який інший користувач на головному екрані вводить 6-значний код або переходить за посиланням -> список завантажується та зберігається локально.
3. **Синхронізація в реальному часі:** Коли будь-хто з учасників додає новий товар, змінює кількість чи викреслює куплений товар — зміни миттєво з'являються на екранах усіх учасників через Firestore `addSnapshotListener`.
4. **Анонімний вхід:** Без реєстрації через пошту/пароль — автоматичний Firebase Anonymous Auth.
5. **Офлайн-стійкість:** Firestore вбудоване офлайн-кешування забезпечує роботу навіть у супермаркетах з поганим зв'язком (черга оновлень надсилається автоматично при появі мережі).
