## 1. Політика конфіденційності (Privacy Policy Draft for Google Play)

### Вступ
Застосунок «Список покупок» (розробник Volodymyr Saveliev) розроблено з повагою до приватності кожного користувача. Наш базовий принцип: **ваші особисті дані належать тільки вам**.

### 1. Збір та передача даних
- **Локальні списки:** За замовчуванням усі списки, категорії та історія зберігаються виключно локально на вашому пристрої у захищеній SQLite базі даних Room.
- **Спільні групові списки:** Якщо користувач створює спільний список або приєднується до нього за 6-значним PIN-кодом, дані цього конкретного списку (назва списку, товари, кількість) синхронізуються через захищену хмарну базу даних Google Cloud Firestore для забезпечення доступу всім учасникам групи.
- **Анонімність:** Для спільних списків використовується анонімна автентифікація (Firebase Anonymous Auth). Застосунок **НЕ збирає** персональних даних (ім'я, електронну пошту, номер телефону, контакти чи геолокацію).
- Застосунок не передає дані комерційним третім особам для продажу або профілювання.

### 2. Дозволи застосунку (Permissions)
- Застосунок **не запитує** дозволів на доступ до контактів, камери, геолокації, мікрофона чи сховища файлів.
- `android.permission.INTERNET` та `ACCESS_NETWORK_STATE`: використовуються виключно для синхронізації спільних групових списків у реальному часі через Firebase Firestore (та відображення банера в майбутньому).

### 3. Безпека даних
- Усі дані в транзиті між пристроєм та серверами Firebase шифруються за протоколом TLS (HTTPS/WSS).
- Будь-який створений спільний список може бути видалений його автором, або товари можуть бути очищені учасниками.
- Видалення застосунку з пристрою автоматично призводить до повного та незворотного видалення всіх локальних списків покупок.

## 3. План монетизації та інтеграція реклами (AdMob Roadmap)

### Стратегія монетизації:
- Застосунок є повністю безкоштовним для користувача.
- Заробіток здійснюється через відображення одного адаптивного банера Google AdMob.

### Захист від втрати користувачів (Retention Safeguard):
- **СУВОРА ЗАБОРОНА реклами на екрані покупок (List Details):** Поки користувач ходить супермаркетом і викреслює позиції, застосунок працює з максимальною швидкістю без банерів, що заважають, чи випадкових кліків.
- **Відсутність відео-інтерстишелів:** Жодної блокуючої реклами на весь екран при запуску програми чи створенні списку.
- Банер розміщується виключно внизу головного екрана списків.

### Порядок увімкнення реклами (для Етапу 6–7):
1. Отримати від Власника рекламні ID AdMob (App ID та Banner Ad Unit ID).
2. Занести залежність `com.google.android.gms:play-services-ads` у `docs/THIRD_PARTY.md`.
3. Додати дозвіл `INTERNET` та оновити Data Safety у Play Console згідно з вимогами Google AdMob.
4. До цього моменту в MVP використовується чистий офлайн-режим.
