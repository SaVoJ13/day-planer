## 1. Оточення Windows і шляхи
- **Урок 001:** У системній змінній PATH за замовчуванням може бути відсутній прямий виклик `java` чи `javac`, проте повноцінний OpenJDK (JBR 25) присутній у складі Android Studio за адресою: `C:\Program Files\Android\Android Studio\jbr\bin\java.exe`. При запуску Gradle чи збірок з консолі PowerShell слід переконатися, що `JAVA_HOME` встановлено на `C:\Program Files\Android\Android Studio\jbr`.
- **Урок 002:** Android SDK розташований у `C:\Users\cocro\AppData\Local\Android\Sdk`. Платформи API 34, 35, 36 та build-tools 34, 35, 36 вже попередньо завантажені. Емулятори AVD наразі не створені, тому перевірки на емуляторі потребуватимуть або створення AVD через `avdmanager`, або використання Android Studio / фізичного тестування.
