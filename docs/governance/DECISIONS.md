## [Р-002] 2026-11-20 — Вибір базового технологічного стеку для Android-застосунку
- **Хто прийняв:** Агент 0 (технічне рішення в межах делегування п. 3.1).
- **Контекст:** Репозиторій містив лише порожній `README.md`. Локальне середовище Власника містить Windows 11, Android Studio (JBR 25), Android SDK (API 34, 35, 36) та adb.
- **Рішення:**
  1. Базовий стек: **Android Native** (100% Kotlin).
  2. UI: **Jetpack Compose + Material Design 3** — сучасний декларативний UI для швидкої побудови адаптивних, локалізованих екранів із підтримкою темної теми.
  3. Локальна БД: **Room SQLite** — надійне типобезпечне збереження списків, категорій, шаблонів та історії товарів.
  4. Архітектура: MVVM з Android ViewModel, Kotlin Coroutines і StateFlow.
  5. Цільові SDK: `minSdk: 24` (покриття >95% пристроїв), `targetSdk: 35` / `compileSdk: 35` (актуальні вимоги Google Play).
- **Наслідки:** Легкий, автономний, швидкий застосунок без важких надлишкових сторонніх фреймворків.

## [Р-003] 2026-11-20 — Політика Zero Network для MVP першого релізу
- **Хто прийняв:** Агент 0 (посилення безпеки та приватності згідно з п. 3.2 Конституції).
- **Контекст:** У промті зазначено, що рекламні SDK, бекенд, синхронізація, камери та аналітика не повинні включатися до MVP без окремого затвердження Власника.
- **Рішення:**
  1. У `AndroidManifest.xml` для MVP **не додавати** дозвіл `android.permission.INTERNET`.
  2. Застосунок є на 100% офлайновим, що гарантує абсолютну конфіденційність користувацьких даних (Data Safety = «Дані не збираються і не передаються третім особам»).
  3. Питання інтеграції рекламного банера чи аналітики виноситься в `OWNER_INBOX.md` як окремий стратегічний етап для затвердження Власником.
