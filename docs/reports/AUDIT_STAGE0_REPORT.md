## 4. Створена Governance-структура
У директорії `docs/governance/` створено повну систему пам'яті проєкту:
1. `CONSTITUTION.uk.md` / `CONSTITUTION.en.md` — вищий керівний документ версії 2.0.
2. `PROJECT_PROFILE.md` — профіль проєкту із заповненням 🔧-параметрів (рівень автономії, ролі, технологічний стек, обмеження).
3. `DEFINITION_OF_DONE.md` — критерії готовності завдань та етапів (включно з правилами 4 мов, офлайн-безпекою та забороною самоверифікації).
4. `CURRENT_STATE.md` — актуальний знімок стану проєкту.
5. `TASK_BOARD.md` — дошка завдань на 8 етапів (Етапи 0–7).
6. `DECISIONS.md` — журнал рішень (Р-001: Конституція v2.0, Р-002: Стек Kotlin + Compose + Room, Р-003: Політика Zero Network для MVP).
7. `LESSONS.md` — журнал виявлених уроків та пасток середовища.
8. `OWNER_INBOX.md` — перелік рішень, що очікують на схвалення Власника.
9. `docs/THIRD_PARTY.md` — реєстр ліцензій сторонніх компонентів.
10. `docs/tasks/TASK-000-stage0-audit-and-governance.md` — картка поточного завдання.
